# Conformance matrix

One row per claim in the business model. Layer is the lowest layer that proves the claim: **domain** (pure functions, Vitest, `pnpm test`), **service** (real services against the embedded PostgreSQL, `pnpm test:service`), **API** (Playwright requests against the running app), **UI** (Playwright with `data-testid` selectors, phone 390×844 and desktop 1440×900). Every claim marked UI has a Playwright assertion. Status is from the run recorded in `report.md`; "fixed" means the claim failed first, was filed in `drift.md`, and passes after the fix commit.
